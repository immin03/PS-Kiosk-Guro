# 아케이드 게임 규칙

키오스크 「더 보기 › 아케이드」의 게임 규칙을 모은 문서(2026-11-26).
숫자는 코드 안 상수가 기준이고, 아래 「숫자」 표는 그 값을 옮겨 적은 것. 둘이 다르면 `test/arcade-rules.test.mjs` 가 실패한다.
게임 문구는 한국어 전용.

## 파미빵 타이쿤

코드: `src/pamibread/tycoon.js`(규칙), `grillEngine.js`(3D 화면), `PamiBreadGame.jsx`(화면 틀)

### 지금 규칙

- 한 판 60초. 틀 6개(3×2).
- 빈 틀을 누르면 고른 속(팥 또는 슈크림) 반죽이 들어간다.
- 테두리가 민트일 때 눌러 뒤집고, 한 번 더 민트일 때 눌러 꺼낸다. 덜 익었을 때 누르면 넘어가지 않는다.
- 너무 오래 두면 주황(조금 탐)을 지나 타고, 탄 빵은 눌러서 버린다.
- 꺼낸 빵은 쟁반에 모인다(최대 8개). 쟁반이 차면 더 꺼낼 수 없다.
- 손님은 최대 3명까지 서고, 처음엔 1~2개, 20초 뒤엔 1~3개를 주문한다. 시간이 갈수록 기다리는 시간이 짧아진다.
- 손님을 누르면 주문만큼 쟁반에 있을 때만 건넨다. 잘 구운 빵부터 준다.
- 받는 돈: 개당 1,000원, 두 면 다 알맞게 구운 빵은 개당 300원 팁, 손님이 절반도 안 기다렸으면 500원 보너스.
- 스탬프: 3개 팔 때마다 하나, 최대 5개.

### 숫자

| 상수 | 값 | 뜻 |
|---|---|---|
| `ROUND` | 60 | 한 판(초) |
| `MOLDS` | 6 | 틀 개수 |
| `COOK` | 3 | 한 면이 알맞게 익는 시간(초) |
| `MIN_TAP` | 0.5 | 이보다 덜 익으면 눌러도 안 넘어감 |
| `READY` | 0.75 | 여기부터 민트(알맞음) |
| `PERFECT_HI` | 1.35 | 여기부터 주황(조금 탐) |
| `BURN` | 1.9 | 여기서 탐 |
| `PRICE` | 1000 | 개당 값(원) |
| `TIP` | 300 | 잘 구운 빵 팁(원) |
| `FAST_BONUS` | 500 | 빨리 건넨 보너스(원) |
| `TRAY_MAX` | 8 | 쟁반 칸 |
| `MAX_CUSTOMERS` | 3 | 한 번에 서는 손님 |
| `STAMP_EVERY` | 3 | 스탬프 하나에 필요한 판매 개수 |
| `STAMP_MAX` | 5 | 스탬프 최대 |

익음 값은 「한 면 굽는 시간 ÷ `COOK`」. 1 이 딱 알맞음.

## 파미탑

코드: `src/pamitop/cut.js`(규칙), `pamiShape.js`(파미 얼굴 칼선), `stackEngine.js`(3D 화면), `PamiTopGame.jsx`(화면 틀)

### 지금 규칙

- 하얀 파미 얼굴 모양 층이 좌우 · 앞뒤로 번갈아 움직인다. 아래 층과 겹칠 때 화면을 누른다.
- 어긋난 만큼 잘려 나가고, 남은 부분만 다음 층의 크기가 된다(얼굴도 같이 잘림).
- 어긋남이 한 변의 5% 안이면 퍼펙트: 잘리지 않는다. 퍼펙트가 3번 이어지면 한 변이 4씩 다시 넓어진다(처음 크기까지).
- 하나도 안 겹치면 끝.
- 속도는 층마다 3씩 빨라진다(140에서 시작, 260까지).
- 스탬프: 5층마다 하나, 최대 5개.

### 숫자

| 상수 | 값 | 뜻 |
|---|---|---|
| `FULL` | 100 | 첫 층 한 변 |
| `PERFECT_EPS` | 0.05 | 퍼펙트로 치는 어긋남(한 변 대비) |
| `GROW_AFTER` | 3 | 다시 넓어지기 시작하는 퍼펙트 연속 |
| `GROW_STEP` | 4 | 한 번에 넓어지는 양 |
| `STAMP_EVERY` | 5 | 스탬프 하나에 필요한 층 |
| `STAMP_MAX` | 5 | 스탬프 최대 |

속도 식: `speedFor(index) = min(260, 140 + index × 3)`.

### 랭킹 연동(파미빵 타이쿤 · 파미탑 · 파마스퀘어 월드 같은 구조)

| 항목 | 지금 | 바꿀 안 |
|---|---|---|
| 손님 구분 | 게임은 기록 없음. 월드는 닉네임과 익명 키로 진행 저장(Supabase `world_players`) | 게임도 월드와 같은 손님 기록을 씀 |
| 점수 저장 | 없음 | 게임 끝 화면 QR → 손님 휴대폰에서 열면 그 손님 기록에 점수가 붙음 |
| 회원 | 월드에서 동의 후 카운터 4자리 코드로 확인 | 회원은 순위표에 회원 표시. 비회원은 저장 화면에서 닉네임을 만들고 회원 확인을 요청하도록 안내 |
| 순위표 | 없음 | 아케이드 게임 카드 아래 지점별 이번 주 TOP 10, 월드 「내 기록」 창에도 |
| 지점 | 월드 서버가 하남만 받음 | 구로도 받음 |
| 전화번호 | 저장 안 함 | 그대로 저장 안 함 |

랭킹 서버 쪽(표 · 함수)은 반영할 때 `ps-os-engine/supabase/world-players.sql` 옆에 SQL 파일로 둔다. 운영 Supabase 에 더하는 변경이라 승인 뒤에 한다.
