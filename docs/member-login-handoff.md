# 회원 로그인용 회원 데이터 — 인수인계

2026-11-27, 아케이드 랭킹 작업(키오스크 `feature/bungeo-stamp-game`, ps-os `supabase/world-game-scores.sql`)에서 요청.

## 왜 필요한가

- 손님이 휴대폰으로 파미빵 타이쿤, 파미탑을 하고 이번 주 랭킹에 올린다.
- 회원이면 휴대폰에서 바로 로그인해 순위표에 「회원」 표시를 붙이고, 퀘스트 보상도 받게 한다.
- 지금은 회원 여부를 알 길이 카운터뿐이다. 직원이 POS 에서 조회하고 월드 기록에 「회원 확인됨」 을 찍는다. SNSPOS 에는 공개 API 가 없다.
- 그래서 회원 명단을 우리 쪽에 두고, 휴대폰 번호로 대조하려 한다.

## 받고 싶은 것

회원 한 명이 한 줄이다. 두 지점 회원을 한 표에 둔다.

| 칸 | 예 | 필수 | 설명 |
|---|---|---|---|
| `member_no` | 0001234 | 필수 | SNSPOS 고객 번호. 다시 올려도 같은 사람을 같은 줄로 잇는 열쇠 |
| `store` | hanam, guro | 필수 | 가입 지점 |
| `phone_hash` | (64자) | 필수 | 휴대폰 번호의 HMAC-SHA256. 번호는 숫자만 남긴 `01012345678` 꼴로 맞춘 뒤 서버 비밀 값으로 해시한다 |
| `phone_last4` | 5678 | 필수 | 뒷 4자리. 화면에 「010-****-5678 로 로그인됨」 을 보여 줄 때만 쓴다 |
| `joined_at` | 2026-09-14 | 있으면 | 가입일 |
| `status` | active, left | 필수 | 탈퇴는 줄을 지우지 말고 left 로 |
| `channel` | pos, kiosk, qr | 있으면 | 가입 경로(`catalog/member-channels.json` 과 같은 말) |
| `updated_at` | 2026-11-27 | 필수 | 이 줄을 마지막으로 반영한 날 |

## 넣지 않는 것

- 이름, 생년월일, 주소, 이메일, 구매 내역, 적립금은 넣지 않는다.
- 휴대폰 번호 원문은 저장하지 않는다. 엑셀 원본은 해시만 뽑고 지운다(또는 드라이브 접근 제한 폴더에만 둔다).

## 두는 곳

- Supabase(jdondfrukwetncyxwrtt) 새 표 `pos_members`를 쓴다.
- RLS 를 켜고 정책은 두지 않는다. anon 은 표를 못 읽는다. 대조는 security definer 함수 하나로만 한다. 기존 `world_*` 함수와 같은 꼴이다.
- 올리는 길은 SNSPOS 백오피스 엑셀 내보내기를 스크립트(ps-os `tools/`)로 읽어 해시를 만들고 upsert 하는 것이다. 키는 `member_no` 다.
- 해시 비밀 값은 Supabase 비밀 값과 스크립트 환경 변수에만 둔다. 저장소에는 넣지 않는다.

## 이 데이터로 할 일(아케이드 쪽에서 만든다)

1. 손님이 휴대폰 번호를 넣는다.
2. 본인 확인을 한다. 방법은 아직 정하지 않았다.
   - 문자 인증: 비용이 든다.
   - 카운터 4자리 확인: 지금 있는 기능이다.
3. 서버에서 `phone_hash` 로 `pos_members` 의 active 줄을 찾는다.
4. 있으면 월드 손님 기록 `world_players` 의 `member` 를 `verified` 로 바꾸고, `member_no` 를 잇는다.
   - 다음부터 그 휴대폰은 계속 회원이다.
   - 다른 휴대폰에서는 같은 번호로 다시 로그인하면 같은 기록으로 이어진다.
5. 없으면 「아직 회원이 아니에요」 와 함께 회원가입 버튼을 보여 준다.

## 정리하는 쪽에 묻고 싶은 것

- 두 지점 회원이 SNSPOS 중앙 서버 한 곳에 있는데, 한 사람이 두 지점에 따로 가입한 경우 고객 번호가 하나인지 둘인지.
- 회원 조회 열쇠가 다르다. POS 는 뒷 4자리, 키오스크 가입 건은 가운데 4자리다(`catalog/pos-vendor.json` 2026-08-03). 엑셀에는 전체 번호가 나오는지.
- 엑셀 내보내기에 가입일, 가입 지점, 탈퇴 여부가 칸으로 있는지.
- 얼마나 자주 다시 올릴 수 있는지(주 1회면 그 사이 신규 가입자는 카운터 확인으로 메운다).
- 개인정보 처리 동의 문구에 「회원 여부 확인용 번호 해시 보관」 이 들어가는지. 지금 월드 동의 문구는 「전화번호는 저장하지 않아요」 라서 고쳐야 한다.
